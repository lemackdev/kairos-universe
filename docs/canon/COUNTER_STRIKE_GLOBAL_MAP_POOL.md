# Counter-Strike Global Map Pool — Canon Directive

> Author-confirmed canon directive, recorded directly from the author's instructions (no episode prose depicts this as an in-universe announcement). See `data/sources/source-canon-directive-cs-map-pool.json` and `data/rulesets/counter-strike-global-map-pool.json`.

## Rule

The Kairos Universe continuity uses one permanent, global, fictional Counter-Strike map pool:

- Cobblestone
- Inferno
- Nuke
- Overpass
- Dust II
- Train
- Cache

This pool applies to all competitive tiers (Tier 1 and Tier 2), all teams (Kairos and non-Kairos), and all organizers in this continuity. There is no rotation and no scheduled end date.

The following real-world Counter-Strike maps are explicitly excluded from any official competition in this continuity:

- Mirage
- Ancient
- Anubis
- Vertigo

## Scope and non-retroactivity

This is a going-forward ruleset. It does not rewrite prior narrative history: episode-093's recap of the Kairos vs. Team Liquid private scrim still references Mirage, Dust II, and Nuke as the maps played in that earlier, un-ruled scrim. The map pool directive governs official competitions from the point this canon record exists onward, and does not retcon that historical scrim.

## Reuse

Future competition records should reference this ruleset by id (`counter-strike-global-map-pool`) via an optional `rulesetIds` field on `competition.schema.json`, instead of duplicating the map list per competition.
