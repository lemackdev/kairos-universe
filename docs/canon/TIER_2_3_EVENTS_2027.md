Scheduling rules applied: every event starts in March 2027 or later, none runs
in July (the competitive break), none overlaps a Major, and none overlaps
another event in this batch. March and April are dense with Premier events, so
three early events overlap other events: ZOTAC Cup Masters Cordoba (Challenger
League 51, PGL Chicago), DreamHack Open #1 (Challenger League 51, FISSURE
London) and Americas LAN #1 (BLAST Austin). Later events overlap only Tier 2
events (CCT North America #2, Elisa Masters Seattle, ESL Challenger League 52
and 53, Thunderpick Masters).

No participants, invites, format, seeding, results, standings or qualification
are established. The existing Counter-Strike map pool ruleset applies.
