# Country Flag Assets

Local PNG icons downloaded from https://flagcdn.com/48x36/{code}.png.
Provider: [Flagpedia / FlagCDN](https://flagpedia.net/download/api), based on
Wikimedia Commons flag artwork. Codes: us, ca, mx, cl, br, kr, cn, eu, jp.
Rendered at 24 x 18 CSS pixels; no emoji or runtime CDN request is used.

Flags display nationality, not a team's region or a temporary training location,
except on the real-world teams table, where a single representative flag
stands in for a multi-country competitive region (e.g. `eu` for Europe,
`jp` for Pacific, `us` for North America).
